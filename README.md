# Portafolio — Aplicación del modelo ECO-RED Normalista

Página del portafolio digital que documenta la aplicación del modelo **ECO-RED Normalista** a dos RED: W3Schools Python Tutorial (4,03/5 · 80,6 %) y Codecademy Learn Python 3 (3,58/5 · 71,7 %), con evidencias por indicador, análisis comparativo frente a LORI y COdA, respuestas a las preguntas de la AAA y referencias (APA 7.ª ed.).

- **Autor:** William Darío Gómez Vega
- **Programa:** Especialización en Aplicación de TIC para la Enseñanza — CVUDES / Universidad de Santander (UDES)
- **Módulo:** Evaluación de Recursos Educativos Digitales — Entregable 2
- **Institución de contexto:** Escuela Normal Superior Francisco de Paula Santander, Málaga, Santander (Colombia)
